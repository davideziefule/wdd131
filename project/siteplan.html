Color Schema

  • White - #FFFFFF: Backgrounds.
  • Dark Charcoal - #333333: Body text.
  • Navy Blue - #003366: Primary headings.
  • Amber - #FFBF00: Accent buttons.

Typography

  • Montserrat: Used for headings to create a bold, modern look.
  • Roboto: Used for body text to ensure clean, readable text.
